# ADRF26 interactive agenda

Static GitHub Pages site with an interactive agenda for the AI, Data, Robotics Forum 2026.

## Files

- `index.html`: page structure
- `styles.css`: visual style inspired by ADR Forum branding
- `agenda.js`: agenda dataset used by the UI
- `app.js`: interactive filtering and rendering logic

## Publish with GitHub Pages

1. Open repository **Settings** → **Pages**.
2. In **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/** (root)
3. Save and wait for deployment.

Your site URL will be:

`https://agonzat.github.io/adrf26/`
